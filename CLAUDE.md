# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

RMIT_Jam is a Unity game-jam project (Unity **6000.5.4f1**, URP 17.5, new Input System 1.19, TextMeshPro, uGUI). Only the front-end menus exist so far; gameplay has not been added.

## Building and running

There is no CLI build script, test assembly or linter. Open the project in the Unity Editor (the version above) and press Play, or build via File > Build Profiles. The `.csproj`/`.slnx` files are generated by Unity, so don't edit them by hand. `Library/`, `Temp/`, `Logs/` and `UserSettings/` are Unity caches.

`com.unity.test-framework` is installed, but no test assemblies exist yet. Tests would run through the Test Runner window or `Unity -batchmode -runTests -projectPath . -testPlatform EditMode`.

## Architecture

- **Scenes** (build order from `ProjectSettings/EditorBuildSettings.asset`): `MainMenu` (index 0), then `CreditsScene`. Scenes change by name through `SceneManager.LoadScene`.
- **All gameplay/UI code** is in `Assets/Scripts/UI Scripts/`: small, independent MonoBehaviours with no shared base class, managers or singletons. Wiring happens in the Inspector: references are `[SerializeField]` fields, and button actions are public methods hooked up through `Button.onClick` in the scene files. If you rename a public method or a serialized field, those scene bindings break silently. Check the `.unity` YAML or tell the user to re-wire.
- **Main menu flow**:
  - `MenuSlideIn` animates the buttons in after a delay.
  - `SceneChanger` handles Play, Credits and Quit.
  - `SettingsCameraTransition` rotates the main camera with a Slerp to a `settingsView` transform to "open" settings instead of loading a scene. It saves the default values of the sliders, toggles and dropdowns in `Awake` and restores them in `ResetSettings`.
  - `ResolutionsSettings` maps the dropdown index to a fixed list of resolutions.
- **Credits**: `CreditsScript` scrolls a RectTransform, and `BackButton` loads `MainMenu`.
- **Animation convention**: hand-written coroutines with smoothstep easing (`t*t*(3-2t)`), not DOTween or Animator. UI that must animate while the game is paused uses `Time.unscaledDeltaTime`.

## Known gotchas

- `SceneChanger.gameScene1` defaults to `"Movement"`, a scene that is not in the project or the build settings yet. Play will fail until that scene is added, or until the field is changed in the Inspector.
- `ShowTextWhenLookingUp` calls `gameObject.SetActive(false)` on itself from `Update`. Once it is hidden, `Update` stops running, so it never shows again.
- Code comments and log messages are partly in Vietnamese. Follow the style of the file you are editing.
- `Assets/TutorialInfo/` and `Assets/Readme.asset` are leftover URP template boilerplate.
